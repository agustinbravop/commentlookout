# Extension feature requests

These are the original ten **extension** ideas. The later Short-video batch desk and Instagram grid planner app concepts overlap with #2 and #1; the newsroom widget, WhatsApp handoff, and download campaigns are separate standalone app concepts. Every link below goes to a specific Zernio request, not the general roadmap. A request is evidence of demand, **not** proof that Zernio has not since shipped it.

| # | Feature | What was requested | Extension scope and constraint |
|---:|---|---|---|
| 1 | Instagram feed planner | [Feed preview](https://requests.zernio.com/p/feed-preview): a commenter specifically asks for a 3×3 preview before scheduling. [Grid simulation](https://requests.zernio.com/p/instagram-feed-preview-grid-simulation): scheduled posts together, draggable to simulate the grid. | **Built:** sample or local-image preview; no live posts or schedule writes yet. |
| 2 | Bulk short-video scheduler | [15–30 short videos](https://requests.zernio.com/p/bulk-video-upload-for-youtubetiktokfacebook-short-videos) and [50-video drag-and-drop instead of CSV](https://requests.zernio.com/p/bulk-50-video-upload-drag-and-drop-not-csv). The [alternative-to-CSV request](https://requests.zernio.com/p/recommend-this-alternative-to-csv-bulk-upload) also asks for video titles and descriptions per file. | Uploading, validating, retrying and scheduling many large files is substantial; start with a review desk and drafts. Drive import and asset reuse are **not** established by these three requests. |
| 3 | Collaborative draft review | [Post approvals workflow](https://requests.zernio.com/p/post-approvals-workflow): approve, reject with comments, request changes; a comment adds multi-stage and external approvers. [Draft notes](https://requests.zernio.com/p/draft-posts-notes) asks for team context on post cards. | The [review API](https://docs.zernio.com/posts/review-post) accepts a decision, not comments; a shared workflow needs more than local extension storage. |
| 4 | Reusable post templates | [Templates for time slots and selected accounts](https://requests.zernio.com/p/templates-for-time-slots-and-selected-social-media-accounts): named defaults on Create post, including account and time-slot selection. | Local presets are easy, but [Reuse Post](https://requests.zernio.com/changelog/new-duplicate-any-post-in-1-click) already covers duplication. |
| 5 | Bulk image-post composer | [Alternative to CSV bulk upload](https://requests.zernio.com/p/recommend-this-alternative-to-csv-bulk-upload): select ~15 local images and edit a title, description, date and platform for each. | Needs file uploads and API credentials to create real drafts; visual cards alone can work locally. |
| 6 | Video retention explorer | [Video retention graph in analytics](https://requests.zernio.com/p/video-retention-graph-chartwithupwardstrendchartwithdownwardstrendchartwithupwardstrend-in-analytics): per-video retention across platforms. A Zernio team comment says the YouTube curve is API-only and no dashboard chart exists for it. | [YouTube curve API](https://docs.zernio.com/analytics/get-youtube-video-retention) needs connected, eligible videos; do not promise equivalent curves for every platform. |
| 7 | Queue shuffle | [Queue Shuffle option](https://requests.zernio.com/p/queue-shuffle-option): randomize the order of queued posts so bulk-uploaded topics are mixed. | Preview safely. Queue-slot `reshuffleExisting` is **not** random post ordering; changing live schedules needs verification. |
| 8 | LinkedIn PDF carousel proofing | [Preview PDFs for carousels on LinkedIn](https://requests.zernio.com/p/preview-pdfs-for-carousels-on-linkedin). The public request has a title but **no explanatory body**. | Local PDF preview is feasible; swipeable slide proofing is our interpretation, not wording from the request. |
| 9 | Post library with notes and tags | [Draft posts notes](https://requests.zernio.com/p/draft-posts-notes): notes to pass post context between teammates. [Post custom tags](https://requests.zernio.com/p/post-custom-tags): find posts in a recurring series. | The [post API](https://docs.zernio.com/posts/create-post) supports tags/metadata; shared notes need authenticated writes, not browser-local storage. |
| 10 | Clipboard-first image composer | [Paste image from clipboard](https://requests.zernio.com/p/paste-image-from-clipboard-with-ctrlvcmdv): paste directly into Create post. [Crop image](https://requests.zernio.com/p/crop-image): quick 1:1 Instagram crop, possibly other ratios. | An extension can paste/crop locally; writing into Zernio's native composer is fragile, so use a separate draft flow. |

The extension augments the signed-in Zernio dashboard only for people who install it. The inspected account had no posts or connected Instagram account, so a live feed remains unverified. API-powered features require appropriately scoped credentials.
